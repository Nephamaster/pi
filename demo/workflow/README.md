交互方式：

- 点击执行节点：查看员工、目标、输入、交付物、工具、权限和返工配置；
- 点击节点下方 Gate：查看机械标准、语义标准、Reviewer 和 PASS/REWORK/BLOCKED 路由；
- 点击 Final Gate：查看整体交付验收；
- 点击底部 ST Core：查看治理成员的职责；
- 使用右上角按钮缩放画布，按 Escape 返回总览。
